Familien Einkauf – Version 23

Neu in v23:
- Produktfoto beim Registrieren eines neuen Produkts auswählen
- Produktfoto bei bestehenden Produkten hinzufügen oder ersetzen
- Produktfoto bei bestehenden Produkten entfernen
- Fotos werden in Supabase Storage gespeichert und auf allen Geräten angezeigt
- Kleine Produktbilder in Suche, Katalogverwaltung und Einkaufslisten
- Bilder werden vor dem Upload automatisch auf max. 1200 px verkleinert und als JPEG komprimiert
- Suchsortierung aus v22 bleibt bestehen
- Mengen/Masseinheiten aus v21 bleiben bestehen

WICHTIG:
1. Zuerst supabase_v23_produktfotos_einrichten.sql im Supabase SQL Editor ausführen.
2. Danach index.html auf GitHub ersetzen.
3. Die übrigen Dateien müssen nur ersetzt werden, wenn sie auf GitHub noch fehlen.
